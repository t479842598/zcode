# Zcode_满血_青棠 v3.14.4 — 官方活动额度入口

基于自托管 3.14.3，新增官方活动/赠送额度入口，并把客户端版本提升到 3.14.4，便于现有客户端通过自建更新清单识别新包。

## 本次更新

- 设置页新增“官方活动额度”入口。
- 嵌入官方 `zcode.z.ai` rewards 页面，不把活动额度复制到自建服务。
- 通过独立 rewards preload 向官方页面注入当前 OAuth 凭据、语言、主题和账号状态。
- 增加 rewards WebView URL 白名单，非官方 rewards 地址不会获得账号上下文。
- 保留官方 billing/plan 服务和现有自建中继、独立更新源。
