# Zcode_满血_青棠 v3.14.3 — 正式版

基于 ZCode 公开 3.14.3，保留自建中继和独立 GitHub 更新源。

## 本次更新

- 同步官方公开 3.14.3 工作流能力：运行中调整并发上限、修改重启复用、较大工作流的状态与有界展示，以及保存、列表、历史、实例图和续跑链路。
- 修复手机远控 RPC 缺失回执导致的约 45 秒周期重连；旧桥、坏帧不回 ACK，重复帧只补 ACK 而不重复执行。
- 手机任务列表按现有 Agent 实时会话状态修正陈旧的“已完成”展示，不因查看列表额外启动 Agent。
- 新对话草稿底部显示 `Zcode_满血_青棠`、本地仓库与 [GitHub 项目](https://github.com/t479842598/Zcode_Full)；侧栏移动远控入口加大并提高对比度。
- 自建中继注册密钥保护、旧设备撤权与日志脱敏；发布脚本移除硬编码密码回退。
- 通用设置仅只读展示官方版本与更新内容，实际自托管安装仍使用本项目 GitHub 产物。

## 验证与边界

- macOS arm64 生产身份包：`dev.zcode.app`，版本 `3.14.3`。构建通过运行时依赖与大小检查。
- `pnpm typecheck`、CLI 构建、架构检查通过；工作流 A/B/C/D 离线合同回归、relay 本机模拟回归通过。全仓 lint 存在已知的未跟踪 `index.js` max-lines 错误，不把它写成通过。
- 真机 Safari 长连接、真实工作流端到端及活动额度的服务端准入仍应在安装后复核；发布说明不承诺修改官方活动政策或额度。

当前运行客户端如果已经是 `3.14.3`，仅靠版本号无法识别本次自托管修复包，需使用本 Release 的安装包做受控替换。安装前备份 APP 和业务数据；替换失败可按项目 `docs/2026-09-25-selfhost-replacement.md` 回滚。
